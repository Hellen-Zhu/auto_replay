Playwright 跑用例，通过才导出

02

导出 case 文件

JSON 步骤数据，不是代码，可审计

03

分发免安装包

便携文件夹，直接用本机 Edge

04

PO 双击回放

真实浏览器逐步重跑，自动留证

为什么做

  • PO 不能装软件，也不写代码
  • 复现问题只能靠截图和口述
  • 交易 ID 每次不同，点击录制无法重放
  • 每轮验收都要重复手工操作

PO 拿到什么

  • 用例树：键盘选择、搜索、多选
  • 可换数据：产品、dat 文件、交易 ID
  • 批量执行，可多条同时跑
  • 证据：报告、截图、trace 回放
  • 密码现场输入，不保存

覆盖与进展

  • 44 条用例，覆盖 13 个场景
  • 创建、审批、取消、分配、终止、更替、修改
  • 真实系统首轮：28 条中 23 条通过
  • 下一步：修复 5 条失败，PO 机器试跑
开场一句话：QA 用 Playwright 跑通一次，系统自动导出 case 文件；PO 不装任何软件，双击就能在自己电脑的 Edge 里把同一条用例真实重跑一遍。 演示顺序：1) 打开 runner，展示用例树和搜索；2) 选一条用例，现场输入密码，按 D 换产品或 dat 文件；3) 看浏览器逐步执行；4) 打开 report 和 trace 回放；5) 多选几条批量跑。 数字说明：44 条用例、13 个 spec 是代码中的现状；28 条中 23 条通过是真实系统第一次完整运行的结果，其余用例在 mock 上验证或尚未运行。并行执行、Windows / Edge 上的便携包还需在 PO 机器上确认。
