OREO UAT REPLAY · 原理

录的是“动作”，不是鼠标点击

QA 执行时每个动作都被记录成数据；PO 回放时由同一段代码把这些数据重新执行一遍

QA 录制侧 · Playwright

四层结构，逐层向下调用

Case：场景步骤 Given / When / Then
Flow：业务步骤，如“创建交易”
Page / Component / API：定位器与原子操作
ui.ts：执行每个动作，同时记录下来

共享执行核心 core/actions.js

两侧都调用它来执行每一步，所以 QA 跑通的和 PO 回放的完全一致

case 文件（JSON）

用例通过后自动导出：步骤、定位器、数据，没有代码

PO 回放侧 · 免安装 runner

读数据，逐步执行

选择：用例树中选一条或多条
确认：地址、账号、现场输入密码
执行：本机 Edge 中逐步重跑
留证：报告、每步截图、trace

为什么能重放

记录的是“填写 / 点击 / 校验 + 定位器”，不是坐标；等待由执行核心自动处理

每次不同的值

交易 ID 在运行时从页面或接口响应中取得，存为变量 ${var}，后续步骤引用它

环境、数据、步骤分离

${cfg} 地址和账号只在本机配置；${param} 业务数据随 case 走，PO 可改

前置数据走 API

事件所需的交易由 API 步骤创建，浏览器里只演示被测的操作和结果

OREO UAT REPLAY · RUNNER 功能

PO 双击即用：选用例、确认数据、看着它跑、拿到证据

按 PO 的使用顺序：启动 → 选择 → 运行前确认 → 运行中 → 运行后 → 其他模式

01 · 启动

免安装，双击就跑

  • 便携文件夹自带 Node 和 Playwright，用本机 Edge
  • run-case.bat：回放用例
  • record-session.bat：手动操作录制
  • view-trace.bat：查看历史报告

02 · 选择用例

键盘用例树

  • 按事件分文件夹，↑↓ 移动，→← 展开
  • 直接输入即搜索，Esc 清除
  • Space 勾选多条或整个文件夹，Ctrl+A 全选，批量运行
  • 把 case 文件或文件夹拖进窗口即运行

03 · 运行前确认

数据可改，不改文件

  • 设置和 case 数据列成编号清单，输入编号改值
  • 只对本次生效，case 文件不变
  • Trade ID 留空则新建交易，填入则用已有交易
  • 密码现场输入，只存在内存里

04 · 运行中

看得见、停得下

  • 每个动作前用橙框标出要操作的元素
  • P 暂停，Enter 继续；S 单步执行
  • 批量最多 8 条并行
  • 始终使用真实 risk engine

05 · 运行后

每次运行都留证据

  • 单条跑完浏览器保持打开，可继续查看
  • report.html：按步骤的结果和截图，失败步骤自动展开
  • 截图播放器逐步回看；trace 回看每步页面、网络
  • 批量运行生成汇总报告；同一窗口可连续跑

06 · 其他模式

录制问题，回看历史

  • 录制：PO 手动操作，自动记下点击、输入和截图
  • 生成报告和 trace，整个文件夹发给 QA 复现
  • 查看：本机打开所有历史报告和 trace
  • 只在本机 127.0.0.1 提供，不上传

OREO UAT REPLAY · 给 PO 的快速上手

点一下，看系统在你面前把流程真实走一遍

QA 已把每个 product 的每个 lifecycle event 做成可回放的用例：在你的 Edge 里逐步操作，跑完就有带截图的报告

怎么用 · 三步

不用安装，不用写代码

1

打开文件夹，双击 run-case.bat

2

用 ↑↓ 选一条用例，按 Enter；要跑多条就按 Space 勾选或 Ctrl+A 全选

3

输入自己的密码，看着它跑；跑完报告自动打开

改数据、用已有交易、暂停、单步：用到时再看第 2 页

你能得到什么

看得到、查得清、留得下

亲眼看到

真实 UAT 上自动操作，每一步用橙框标出正在点哪里

覆盖清楚

按 event 分文件夹、每个 product 一条，如 Cancellation – FX_TRF

结果留证

每步截图、失败停在哪一步，可逐张回放，可附到 UAT sign-off

换数据自己试

运行前改 product、comments 等值，不用找 QA

常见问题

你可能想问

要装什么吗？

不用。文件夹拷过去就能用，用电脑上的 Edge

会动到真实数据吗？

只在 UAT 跑，每次自己新建一笔测试交易

密码安全吗？

运行时现场输入，只在内存里，不写进任何文件

跑失败了怎么办？

把报告文件夹发给 QA，里面有截图和完整回放

发现没覆盖的场景？

双击 record-session.bat 手动操作一遍，录制发给 QA 转成用例

只想看结果？不用碰工具：QA 跑完把报告发给你即可
